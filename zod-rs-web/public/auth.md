# Auth.md

## Authentication

zod.rs is the public documentation site for the zod-rs Rust validation library. No authentication is required for anything on this site.

- There is no registration, login, or API key. There are no user accounts and no protected endpoints.
- All content is publicly readable. Every documentation page is also available as markdown: request any page URL with an `Accept: text/markdown` header, or start from the [llms.txt](https://zod.rs/llms.txt) index.
- This site exposes no web API. The zod-rs library itself is distributed through [crates.io](https://crates.io/crates/zod-rs) and developed on [GitHub](https://github.com/maulanasdqn/zod-rs).
